# Surma Construction Limited Website

This is the official website made for [Surma Construction Limited](https://surmaconstructionlimited.com), built using React and CSS.

## How to Run

In the project directory, you can run:

### `npm start`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes, and you may also see lint errors in the console.

### `npm run build`

Builds the app for production to the `build` folder, optimizing it for best performance.

### `npm test`

Launches the test runner in interactive watch mode.
